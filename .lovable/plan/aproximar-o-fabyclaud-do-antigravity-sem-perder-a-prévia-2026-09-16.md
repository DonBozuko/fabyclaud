# Aproximar o FabyClaud do Antigravity sem perder a prévia

## Objetivo

Fortalecer o que já existe para que o sistema execute, confira e publique apenas entregas comprovadas, mantendo a prévia visual e sem anunciar capacidades indisponíveis.

## Entrega desta etapa

1. **Publicação segura**
   - Conferir os arquivos antes de publicar.
   - Bloquear GitHub Pages para projetos que dependem de Flask, Python, Node, React/Vite sem versão estática pronta.
   - Explicar o bloqueio e preservar a publicação anterior.

2. **Teste de IA mais confiável**
   - Trocar o teste “Oi” por uma pequena tarefa estruturada de código.
   - Só marcar a conexão como pronta quando a resposta demonstrar que o modelo consegue seguir instruções básicas de construção.
   - Continuar mostrando o erro real do provedor quando falhar.

3. **Auditoria mais profunda da prévia**
   - Testar abas, menus e telas reveladas por cliques, atualizando a lista de controles durante a auditoria.
   - Registrar erros de clique, imagens quebradas, formulários sem validação e ações sem efeito.
   - Não confundir navegação externa ou páginas de servidor com sucesso testado.

4. **Notas honestas e testes do próprio sistema**
   - Impedir nota máxima quando a entrega só passou por verificação superficial ou depende de servidor ausente.
   - Corrigir o formato dos testes para que o executor geral reconheça o resultado corretamente.
   - Adicionar testes para publicação incompatível e validação da resposta de uma chave.

5. **Proteção do armazenamento público**
   - Manter dados privados bloqueados.
   - Acrescentar limitação de requisições aplicável no ambiente hospedado, sem fingir autenticação de usuários finais.
   - Continuar apresentando esse recurso como armazenamento público simples.

6. **Validação final**
   - Executar testes e verificar a aplicação no navegador.
   - Confirmar os estados: calculadora sem chave, chave não aprovada, projeto estático publicável e projeto de servidor bloqueado.

## Limites honestos

Esta etapa não cria um computador remoto completo para executar qualquer projeto Python/Node, nem torna serviços pagos ilimitadamente gratuitos. Projetos com servidor continuarão sendo identificados e bloqueados até existir um ambiente isolado real; vídeo continuará indisponível até uma integração verificável.
